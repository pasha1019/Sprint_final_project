# Sprint_final_project

API автотесты для учебного сервиса «Доска» — https://qa-desk.education-services.ru

## Структура проекта

```
.
├── conftest.py              # Общие фикстуры (registered_user, registered_user_token, foreign_user, created_listing)
├── data/
│   ├── data.py              # Валидные значения, сообщения об ошибках, генерация данных через Faker
│   └── endpoints.py         # Эндпоинты сервиса
├── helpers/
│   ├── user_helper.py       # Регистрация пользователя
│   └── listing_helper.py    # Создание/редактирование/удаление объявления
├── test/
│   ├── test_registration.py      # Регистрация пользователя
│   ├── test_authorization.py     # Авторизация пользователя
│   ├── test_create_listing.py    # Создание объявления (все категории)
│   ├── test_edit_listing.py      # Редактирование объявления (+ чужое объявление)
│   └── test_delete_listing.py    # Удаление объявления
├── pyproject.toml           # Конфигурация pytest
├── requirements.txt         # Зависимости
└── .gitignore
```

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```

## Покрытые сценарии

1. **Регистрация**
   - Успешная регистрация нового пользователя с уникальным email (Faker, новый email для каждого теста) → 201
   - Повторная регистрация пользователя с уже существующим email → 400 «Почта уже используется»
2. **Авторизация**
   - Успешная авторизация ранее зарегистрированного пользователя → 201 + `access_token`
3. **Создание объявления**
   - Успешное создание объявления во всех категориях (Авто, Книги, Садоводство, Хобби, Технологии) → 201 + проверка в ленте
4. **Редактирование объявления**
   - Успешное редактирование каждого поля (name, category, condition, city, description, price) → 200 + проверка в ленте
   - Редактирование объявления, созданного другим пользователем → 401
5. **Удаление объявления**
   - Успешное удаление → 200 + объявления нет в ленте и в профиле

## Эндпоинты

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/api/signup` | Регистрация пользователя |
| POST | `/api/signin` | Авторизация пользователя |
| POST | `/api/create-listing` | Создание объявления (multipart/form-data) |
| PATCH | `/api/update-offer/{id}` | Редактирование объявления (multipart/form-data, все поля обязательны) |
| DELETE | `/api/listings/{id}` | Удаление объявления |
| GET | `/api/listings/{page}` | Лента объявлений |
| GET | `/api/profile/listings/{page}` | Объявления пользователя |
